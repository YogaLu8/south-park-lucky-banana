# 南方公园：幸运香蕉

一个基于 Ren'Py 的《南方公园》同人视觉小说。

---

## 简介

肯尼，南方公园最穷的小孩，听说卡特曼在卖"幸运香蕉"——吃了能变幸运，五块八一根。

他兜里只有五毛。

于是他决定攒钱。

但他不知道，这根香蕉背后是卡特曼的一整套营销骗局，而他自己，将在一连串愚蠢的意外里，死上很多次。

---

## 特色

- **多结局**：11 个结局，包括 1 个真结局、1 个坏结局、9 个死亡/分支结局
- **道具系统**：手电筒、Mr.Hat、笔记本、篮球，影响分支走向
- **原汁原味的南方公园风格**：脏话、讽刺、角色本色出演
- **隐藏要素**：**联动结局

## 安装与运行

### 方式一：直接下载

1. 下载 Release 中的压缩包
2. 解压
3. 运行 `SouthParkLuckyBanana.exe`（Windows）或对应平台的可执行文件
